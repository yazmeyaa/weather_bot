## Телеграм бот с различным функционалом.
Для корректной работы приложения необходимо указать токен бота в системным переменных (TOKEN).

В этом проекте Вы можете запустить:

### `npm start`
Запуск приложения

### `npm run build`
Сборка приложения

## Команды и возможности бота
### "Чайный, погода %city_name%
Получение информации о текущей погоде\
в указанном городе
